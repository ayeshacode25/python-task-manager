
# Python Task Manager

A simple task management application built using Python.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using JSON
- Keep tasks saved after closing the program

## Requirements

- Python 3

## How to Run

1. Download or clone this repository.
2. Open the project folder in a terminal.
3. Run the following command:

```bash
python main.py
```

## Technologies Used

- Python
- JSON
- Git
- GitHub

This project was created to practise Python programming, functions, file handling, and GitHub.
